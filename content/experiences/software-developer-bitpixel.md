## About the Company

BitPixel Software Solutions is a software company that builds web and mobile products for clients across multiple industries. The engineering culture there emphasizes ownership — developers are expected to take a feature from requirements all the way to production.

## What I Did

I worked as a full-stack developer on client projects, contributing across the entire product lifecycle.

- Built and maintained REST APIs and the frontend interfaces that consumed them.
- Participated in sprint planning, code reviews, and release deployments.
- Investigated and fixed production bugs under time pressure.

## What I Learned

- **Ownership:** being responsible for a feature end-to-end taught me to think about edge cases and failure modes before writing code.
- **Code review:** giving and receiving review feedback improved how I structure code for readability.
- **Deployment discipline:** I got comfortable with CI/CD pipelines and learned to deploy with confidence instead of fear.

## Why It Mattered

This role was where I learned to ship. The combination of client deadlines and a supportive team pushed me to become a faster, more pragmatic engineer while keeping quality high.
