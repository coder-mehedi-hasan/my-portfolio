## Project Scope

This open-source policy plugin extends [Gravitee API Management](https://www.gravitee.io/) with message conversion between JSON and HL7. It is designed for API flows that need to translate between general-purpose JSON payloads and the HL7 format used by healthcare systems.

## My Role

I developed the plugin in **Java** while working at **Interspeed**.

- Implemented the conversion policy for Gravitee's API-management workflow.
- Worked with both JSON payloads and HL7 healthcare messages.
- Packaged the functionality as an open-source Gravitee policy plugin.
