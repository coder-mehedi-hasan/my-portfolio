## Project Scope

LabQFusion LIS is a laboratory information system built to help labs process medical tests efficiently and accurately.

## My Role

I engineered the application across its web, backend, database, and messaging layers.

- Built the web application with Next.js and backend services with Express.js.
- Used MySQL for laboratory and medical-test data.
- Integrated RabbitMQ to support reliable processing workflows.
- Enabled automated scanner data input and AI-assisted analysis for rapid diagnostics.

## Contribution

My work connected laboratory data entry, test processing, and analysis in a system designed to improve diagnostic speed and accuracy.
